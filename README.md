# Asteroids

A Python implementation of the classic arcade game **Asteroids**, built as part of the [Boot.dev](https://boot.dev) curriculum. 

## Current State (Version 1.0)
The foundational version of the game is complete! The core mechanics are up and running, including:
* Fully controllable player ship (rotation, thrust, and rate-limited shooting)
* Procedurally generated asteroid fields
* Asteroid destruction and splitting mechanics
* Circle-based collision detection between the player, bullets, and asteroids

## Planned Improvements
Now that the base game is functional, I am planning to expand and polish the gameplay experience. Upcoming features may include:
- [ ] **Scoring System:** Tracking points for destroying asteroids based on their size.
- [ ] **UI/UX Polish:** Adding a proper Start screen, Game Over screen, and a visible UI for the score and remaining lives.
- [ ] **Player Lives & Invulnerability:** Giving the player multiple lives and a brief invulnerability window upon respawning.
